Quick Scenarios
1. What happens when the masses are equal (\(m_1 = m_2\))? Equilibrium

Try it: Set both masses to 3.0 kg with \(v_0 = 0\text{ m/s}\).

Physical Law: The net external gravitational pulling force is: \[F_{\text{net}} = g(m_2 - m_1) = 0\text{ N}\] Since \(F_{\text{net}} = 0\), system acceleration is \(a = 0\text{ m/s}^2\). The system remains in static equilibrium.

Follow-up: If you give equal masses an initial velocity of \(v_0 = 2\text{ m/s}\), it moves indefinitely at constant velocity—a direct demonstration of Newton's First Law.

2. How does initial velocity affect system trajectory? Kinematics vs Forces

Try it: Set \(m_1 = 2.0\text{ kg}\), \(m_2 = 3.0\text{ kg}\), and \(v_0 = -3.0\text{ m/s}\) (counterclockwise).

Observation: Mass \(m_1\) initially moves DOWN, while acceleration points in the opposite direction (clockwise / positive).

Key Insight: Acceleration determines the rate and direction of velocity change, not the instantaneous direction of motion. The system decelerates, halts momentarily, and reverses direction.

3. What happens when one mass is significantly heavier (\(m_2 \gg m_1\))? Free Fall Limit

Try it: Set \(m_1 = 0.5\text{ kg}\) and \(m_2 = 10.0\text{ kg}\).

Limiting Analysis: As \(m_2 \gg m_1\), the acceleration ratio approaches unity: \[a = g \left(\frac{m_2 - m_1}{m_1 + m_2}\right) \approx g \left(\frac{m_2}{m_2}\right) = g = 9.80\text{ m/s}^2\] Acceleration nears free fall, but can never exceed \(g\) because \(m_1\) contributes inertia to the total system mass.

4. Why is rope tension between \(m_1 g\) and \(m_2 g\)? Internal Force

For the heavier mass (\(m_2\)) to accelerate downward, gravity must win: \(m_2 g > F_T\).

For the lighter mass (\(m_1\)) to accelerate upward, tension must win: \(F_T > m_1 g\).

Therefore, tension is strictly bounded: \[m_1 g < F_T < m_2 g\] Only when \(m_1 = m_2\) does tension equal each weight (\(F_T = mg\)).

1. The System Approach (Whole Machine)

Treating both connected masses as a single one-dimensional system unfolds the Atwood machine along the connecting cord. Internal tension forces cancel out according to Newton's Third Law (\(F_{T1} = -F_{T2}\)).

\[F_{\text{net, ext}} = m_2 g - m_1 g = g(m_2 - m_1)\]

Applying Newton’s Second Law to the combined mass \((m_1 + m_2)\):

\[a = \frac{F_{\text{net, ext}}}{m_{\text{total}}} = \frac{g(m_2 - m_1)}{m_1 + m_2}\]

2. Isolating Individual Masses (Internal Tension)

To determine internal cord tension \(F_T\), we construct free-body equations for each isolated body:

\[\text{For } m_1 \text{ (accelerating up): } F_T - m_1 g = m_1 a \implies F_T = m_1(g + a)\] \[\text{For } m_2 \text{ (accelerating down): } m_2 g - F_T = m_2 a \implies F_T = m_2(g - a)\]

Substituting the system acceleration formula yields the harmonic mean tension equation:

\[F_T = \frac{2 m_1 m_2 g}{m_1 + m_2}\]

Standard classroom convention assumes an ideal massless, frictionless pulley with \(g = 9.80\text{ m/s}^2\).
